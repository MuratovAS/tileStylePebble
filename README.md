# TileStyle — settings page

Страница настроек циферблата [TileStyle](../../tree/main) для Pebble Time 2.
Ветку отдаёт GitHub Pages; код циферблата, ресурсы и генераторы
`js/fonts.js`, `js/icons.js`, `js/sysfonts.js` — в ветке `main`.

В рабочей копии `main` эта ветка подключается в папку `config/`:

    git worktree add config gh-pages

Интерфейс страницы — на английском и русском (`js/i18n.js`): язык задаёт
`?lang=en|ru`, затем переключатель EN / RU в шапке, иначе язык браузера.
